Grok Build draws all TUI colors from a central theme. You can switch themes while Grok is running with `/theme`, have Grok follow your operating system's light/dark appearance automatically, or fine-tune layout, animations, and block styling through `pager.toml`.

---

## Available Themes

Grok includes five built-in themes plus an `auto` option that tracks your system appearance:

| Theme | Config Names | Description | Truecolor Required |
|-------|-------------|-------------|-------------------|
| **GrokNight** | `groknight`, `grok-night`, `dark` | Neutral dark base with a magenta accent. Default theme. Quantizes cleanly on 256-color and 16-color terminals. | No |
| **GrokDay** | `grokday`, `grok-day`, `light`, `day` | Light theme for bright terminal backgrounds. Quantizes cleanly. | No |
| **TokyoNight** | `tokyonight`, `tokyo-night`, `tokyo` | Dark, blue-tinted backgrounds from the Tokyo Night palette. Loses its character when quantized. | Yes |
| **RosePineMoon** | `rosepine`, `rose-pine`, `rosepine-moon`, `rose-pine-moon` | Muted dark palette with mauve accents from the Rosé Pine family. | Yes |
| **OscuraMidnight** | `oscura`, `oscura-midnight` | Deep dark base with purple accents. | Yes |

Theme names are **case-insensitive**. The `auto` option (alias `system`) is documented under [Auto Theme](#auto-theme-system-appearance) below.

<Tip>
Minimal mode (`--minimal`) always renders with your terminal's own palette and ignores theme settings entirely. `/theme` and theme rows in `/settings` are unavailable in minimal mode. See the note at the end of this page for details.
</Tip>

## Switching Themes

### In the TUI

Run the `/theme` slash command (alias `/t`) to open the theme picker. Arrow keys preview each theme in real time; press `Enter` to apply and save, or `Esc` to revert.

To switch without the picker, pass a name directly:

```text
/theme tokyonight
```

Submitting `/theme` on its own — without choosing from the picker — cycles to the next theme.

### Via Config File

Set the theme permanently in `~/.grok/config.toml`:

```toml
[ui]
theme = "tokyonight"
```

## Auto Theme (System Appearance)

Set `theme = "auto"` to have Grok follow your operating system's light/dark mode and switch themes automatically:

```toml
[ui]
theme = "auto"
```

By default, dark mode maps to **GrokNight** and light mode maps to **GrokDay**. Override either mapping with `auto_dark_theme` and `auto_light_theme`:

```toml
[ui]
theme = "auto"
auto_dark_theme = "tokyonight"
auto_light_theme = "grokday"
```

`theme = "system"` is an alias for `theme = "auto"`.

You can also set `GROK_THEME` (or `LC_GROK_THEME`) to force a theme or `auto` without editing `config.toml`.

### How Detection Works

| Platform | Method |
|----------|--------|
| **macOS** | Reads `AppleInterfaceStyle` system preference |
| **Linux** | Queries XDG Desktop Portal (`org.freedesktop.appearance.color-scheme`) |
| **Windows** | Reads the system personalization registry |
| **SSH / tmux / headless** | Checks `GROK_APPEARANCE` or `LC_GROK_APPEARANCE` (`dark`/`light`), then `COLORFGBG`, then a startup OSC 11 background query. `grok wrap ssh …` stamps `LC_GROK_APPEARANCE` from the local OS theme so it survives SSH into the login shell. |

Once running, Grok polls desktop APIs and environment hints every 5 seconds. Toggling your OS between light and dark on a local desktop takes effect within seconds without restarting.

Configure auto dark and light mappings interactively from `/settings` → **Appearance** → **Auto dark theme** / **Auto light theme**.

## Color Support Detection

On startup Grok detects your terminal's color capability and quantizes all theme colors to match:

| Level | Description | Detection |
|-------|-------------|-----------|
| **Truecolor** (24-bit) | Full RGB color. All themes render as designed. | `COLORTERM=truecolor` or equivalent terminal capability |
| **256-color** | Indexed palette. RGB values are mapped to the nearest palette entry. | Standard xterm-256color |
| **16-color** | ANSI names only. Colors map to the closest ANSI color. | Basic terminal support |

When `NO_COLOR` is set in the environment, Grok emits no color and renders in monochrome.

Run `/doctor` to see the detected color level and which themes are available on your terminal. If truecolor is unavailable, Doctor explains the terminal limitation and any relevant setup steps.

GrokNight and GrokDay use neutral grays that quantize cleanly. TokyoNight, RosePineMoon, and OscuraMidnight rely on distinctive tinted backgrounds that lose their character when quantized — the theme picker hides them on non-truecolor terminals.

## Cursor Color

Grok sets your terminal cursor to the current theme's `accent_user` color using the **OSC 12** escape sequence to indicate an active Grok session:

- Applied on startup and on every theme switch.
- Reset to the terminal's default on exit via **OSC 112**.

This works in all modern terminals that support OSC 12.

## Compact Mode

Toggle compact mode with the `/compact-mode` slash command. Compact mode reduces outer vertical padding to zero, minimizes horizontal margins, and tightens the prompt area. Use it on small screens to maximize the content area.

The setting persists to `~/.grok/config.toml` under `[ui].compact_mode` and survives restarts. You can also toggle it from `/settings` → **Appearance**.

---

## Syntax Highlighting

Grok bundles three `.tmTheme` files for code-block syntax highlighting and selects one automatically based on the active theme:

| tmTheme file | Used by |
|--------------|---------|
| `grok-night.tmTheme` | GrokNight, RosePineMoon, OscuraMidnight |
| `grok-day.tmTheme` | GrokDay |
| `tokyo-night.tmTheme` | TokyoNight |

The matching file is selected automatically when you switch themes. The `.tmTheme` files are built into the binary and cannot be replaced with custom files.

## Deep Customization with pager.toml

For fine-grained control, create `~/.grok/pager.toml`. This file governs TUI layout, scrollbar behavior, scroll physics, block styling, animations, and terminal behavior. All settings have defaults — specify only the values you want to override. Changes apply on restart.

Key areas you can control:

| Section | What it controls |
|---------|-----------------|
| `[terminal]` | Alternate screen mode (`auto`, `always`, `never`) |
| `[animation]` | Frame rate (`fps`) and wave cycle length (`wave_rows`) |
| `[prompt]` | Collapse behavior when unfocused, mouse hover highlight |
| `[scrollback.layout]` | Viewport padding: vertical, horizontal, and per-block |
| `[scrollback.scrollbar]` | Show/hide, gap from content, gap from screen edge |
| `[scrollback.scroll]` | Context margins, follow-mode behavior, fold anchoring, manual-fold pinning |
| `[scrollback.display]` | Sticky headers, tab width, expand indicators, dim accents |
| `[scrollback.blocks.edit]` | Diff indentation, hunk separator, dual line numbers, fold shape |
| `[scrollback.blocks.thinking]` | Accent animation, truncated-mode line count, background blend |
| `[scrollback.blocks.tool]` | Bullet style, muted collapsed state, detail dimming |
| `[scrollback.blocks.execute]` | Shell output truncation, header style, accent animation |
| `[scrollback.blocks.prompt]` | User prompt block background, vertical padding |

Example layout customization:

```toml
[scrollback.layout]
outer_vpad = 1
outer_hpad_left = 2
outer_hpad_right = 2
block_pad_left = 2
block_pad_right = 2

[scrollback.scrollbar]
enabled = true
gap_left = 0
gap_right = 0

[scrollback.scroll]
follow_indicator = "center"
follow_auto_select = true
respect_manual_folds = false

[scrollback.blocks.edit]
indent = true
hunk_separator = "…"
dual_line_numbers = false

[animation]
fps = 30
wave_rows = 32
```

<Tip>
**Minimal mode has no theming.** When running with `--minimal`, Grok renders directly on your terminal's own background using its default foreground/background and 16-color ANSI palette — the same colors `git` or `ls` use. This keeps output legible on any light or dark terminal profile without detection or configuration. `/theme` and the theme rows in `/settings` are not available in minimal mode.
</Tip>
