Grok Build (`grok`) is SpaceXAI's terminal-based AI coding agent. It runs as a full-screen, mouse-interactive TUI that understands your codebase, edits files, executes shell commands, searches the web, and manages long-running tasks — interactively, headlessly for scripting and CI/CD, or embedded in editors via the Agent Client Protocol (ACP).

## Get Running in Minutes

<Steps>
  <Step title="Install Grok">
    Run the one-line installer for macOS or Linux:
    ```bash
    curl -fsSL https://x.ai/cli/install.sh | bash
    ```
    On Windows PowerShell:
    ```powershell
    irm https://x.ai/cli/install.ps1 | iex
    ```
    Verify: `grok --version`
  </Step>
  <Step title="Authenticate">
    Launch Grok for the first time — it opens your browser to sign in automatically:
    ```bash
    grok
    ```
    For CI/CD environments, set an API key instead:
    ```bash
    export XAI_API_KEY="xai-..."
    grok
    ```
  </Step>
  <Step title="Start coding">
    Type a prompt and press `Enter`. Grok reads your files, runs commands, and streams results live:
    ```bash
    grok "fix the failing auth tests and run them"
    ```
  </Step>
  <Step title="Extend and automate">
    Add MCP servers, install plugins from marketplaces, write lifecycle hooks, or run headlessly in CI/CD pipelines.
  </Step>
</Steps>
